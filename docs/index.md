## Find your way around Lemon

Lemon is an open-source, local-first AI assistant platform for developers and
technical operators. The supervised Elixir / OTP runtime connects durable
sessions, memory, skills, tools, provider routing, and native multi-agent
execution. Start in the terminal, use the browser, or connect a chat channel.
LemonSim adds deterministic, replay-verified simulation worlds for evaluating agents.
