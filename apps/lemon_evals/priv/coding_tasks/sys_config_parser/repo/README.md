# Service configuration reader

Fix the configuration parser in this C99 project while preserving config.h and the config_dump CLI. cfg_init initializes a fresh cfg; cfg_free releases it, resets it to empty, and is safe to repeat. cfg_get returns a borrowed NUL-terminated value, or NULL for an absent case-sensitive key. cfg_parse parses exactly length bytes without modifying or retaining input. NULL text is allowed only with length zero, which parses an empty document. Parse success returns 0, replaces the previous configuration (not merges), and writes zero to error_line when non-NULL. Syntax, invalid NULL input, or allocation failure returns -1 and leaves the previous configuration unchanged; syntax errors write the physical 1-based line number to error_line (invalid NULL input uses 1). error_line itself may be NULL. The cfg handle must already be initialized and all cfg/key arguments must be valid. Entries are stored in first-occurrence order; duplicate case-sensitive keys replace their value without moving their entry. Every stored key/value is owned by cfg and remains valid independent of input until the next successful parse or cfg_free. Grammar: documents are lines separated by LF or CRLF; the final line need not have a newline. A bare CR or any embedded NUL is invalid even inside comments. Whitespace means ASCII space or tab only. Blank lines and lines whose first non-whitespace byte is # are ignored. Assignments have optional whitespace, a key, optional whitespace, =, optional whitespace, then a value. Keys match [A-Za-z_][A-Za-z0-9_.-]* and cannot be quoted or escaped. Values may be unquoted or double-quoted, determined by their first byte after leading whitespace. An unescaped # starts a comment outside quotes, even without preceding whitespace; # is ordinary inside quotes. Unquoted values end at the first unescaped # or line end; trim literal leading/trailing spaces/tabs before decoding escapes. A raw double quote anywhere in an unquoted value is invalid. A quoted value must close on the same physical line; after the closing quote only whitespace and an optional # comment may follow. Literal spaces/tabs inside quotes are preserved. In either value form, the only supported backslash escapes are backslash-backslash (literal backslash), backslash-double-quote, backslash-#, backslash-=, backslash-n (newline), and backslash-t (tab). Unknown escapes, a final dangling backslash, and unterminated quotes are errors. Escaped # never starts a comment; escaped quotes never close a quoted value. Empty unquoted and quoted values are valid; ordinary = bytes after the assignment delimiter are part of the value. Comments are not escape-decoded, so quotes and backslashes inside them are ignored. Other non-NUL/non-CR/non-LF value bytes are preserved literally, with no variable expansion or Unicode processing. The config_dump CLI reads stdin and prints entries in first-occurrence order as key="value" plus newline; it escapes backslash, double quote, newline, and tab inside values using the supported escapes. It exits 0 on success, 1 on a parse error with stderr exactly 'line N: invalid configuration' plus newline, and 2 on CLI input/allocation failure. Use standard C only; fix ownership and parsing without leaks or undefined behavior. Run make test.

The library is used to reload a live configuration, so preserving the old settings after malformed input matters. The existing scanner mishandles escaped delimiters and quoted tails, and its replacement paths need ownership repairs. Build with `make`, run visible tests with `make test`, and clean with `make clean`.

`LIB` in the Makefile lists the library implementation sources; add helper C files there when splitting the implementation. `make -s print-lib` prints this list for other library consumers.
