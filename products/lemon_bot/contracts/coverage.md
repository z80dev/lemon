# Behavioral coverage — 101 use cases

Normative design coverage, **not exercised test coverage**. The first table preserves all 101 research §20 use cases; the second maps all Muse items 1–16. Latest explicit user scope supersedes live Team parity: personally owned assistants, owned Bot groups and persistent approved iOS QR connection to reachable desktop cluster. No live sharing/managers/publishing/other-human fallback or enterprise-first onboarding. Existing optional configured identity/admin/provider/host controls retain real prerequisites, never grant a live Bot. Screen streaming/demo capture remain excluded. Paths use /v1 except /hooks and MCP; actual applied host revisions are never imaginary enforcement.
